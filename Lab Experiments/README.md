## Repository Structure

Each experiment folder follows a consistent structure:

```text
Experiment-XX-<Title>/
├── README.md          # Complete lab report (Aim, Theory, Procedure, Output, Result, Viva)
├── screenshots/       # Output screenshots referenced directly in README.md
└── ...                # Source code, Dockerfiles, Kubernetes YAML, CI/CD workflows, or data files
```

---

## General Instructions

1. Replace placeholder usernames (such as `<dockerhub-username>` or `<your-username>`) with your own GitHub / Docker Hub handle before running cloud commands.
2. Never commit passwords, API keys, or personal access tokens—store them only as GitHub Secrets or Jenkins Credentials.
3. Stop and clean up local Docker containers and Kubernetes clusters after completing lab sessions.
